# Rainbow

Unity で制作した **2Dトップダウン型ストーリーゲーム** です。  
会話、インベントリ、クエスト、セーブ／ロードなどのRPG基本システムに加え、  
シューティング、迷路、パズルのミニゲームを組み込み、複数の遊び方を体験できる構成にしました。

## 概要

本プロジェクトは、Unity を用いて開発した 2Dトップダウン型のストーリーゲームです。  
虹の色をモチーフにした **7種類のマップ** を制作し、各マップごとに異なるゲーム体験ができるように設計しました。

ゲーム全体には以下の基本システムを実装しました。

- プレイヤー移動
- 会話システム
- インベントリ
- クエスト進行
- セーブ／ロード
- イベント管理

さらに、単調にならないように複数のミニゲーム要素を組み込みました。

---

## 主な実装内容

### 1. マップ構成
虹をモチーフにした全7種類のマップを制作し、  
各エリアごとに異なるミニゲームやイベントを配置しました。

### 2. シューティングミニゲーム
- ステージ進行型のスポーンロジック
- スコア／ライフUI連動
- テキストデータを利用した敵出現制御
- 小型・中型・大型・ボスの出現パターン切り替え

### 3. パズルミニゲーム
- オブジェクト相互作用を利用したギミック実装
- プレイヤー操作による進行型パズル設計

### 4. 迷路ミニゲーム
- 探索を中心とした構成
- マップ理解と移動を活かしたゲーム進行

### 5. 共通ゲームシステム
- 会話システム
- インベントリ管理
- クエスト進行管理
- セーブ／ロード機能
- シーン遷移後の状態維持

---

## 技術的な工夫

### データ駆動型スポーンシステム
ステージごとの敵出現データをテキストファイルから読み込み、  
**出現時間・敵タイプ・出現位置** を動的に制御する仕組みを実装しました。

これにより、
- コードを変更せずに
- テキストデータだけで
- ステージ難易度や出現構成を調整

できる構造にしました。

### Singleton を用いた状態管理
BGM管理、会話システム、ゲームマネージャーなどの主要システムには  
**Singleton パターン** を採用しました。

`DontDestroyOnLoad` を用いてシーン遷移後もインスタンスを保持し、  
重複生成を防ぐことで、状態破損や不具合が起きにくい構成にしました。

## 開発を通じて学んだこと

本作は初めての個人開発作品であり、完成まで到達できた一方で、  
初期設計の重要性も強く実感しました。

完成後に以下の改善を追加したいと考えましたが、

- 解像度設定
- 音量調整機能
- 多言語対応

初期設計段階で拡張性を十分に考慮していなかったため、  
後から組み込むには全体構造の見直しが必要な状態になっていました。

この経験を通じて、**ゲーム開発では初期企画とシステム設計が非常に重要であること** を学びました。
